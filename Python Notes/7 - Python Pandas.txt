# Quick tips & common pitfalls (for beginners)

* When creating DataFrames from dicts, the keys become column names; list lengths must match.
* `df['col']` returns a Series; `df[['col1','col2']]` returns a DataFrame.
* `.loc` is label-based, `.iloc` is integer-position-based — confusing them causes wrong rows/columns.
* `df.info()` shows dtypes and null counts; important to catch strings that should be numeric.
* Use vectorised ops (like `df['a'] + df['b']`) — avoid Python loops over rows for speed.
