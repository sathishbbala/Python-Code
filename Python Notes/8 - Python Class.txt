A class is a blueprint
Object is an instance of a class, thing created from that blueprint

How to create a class? 
class Car:
    pass

How to create an object? 
mycar = Car();

How to add attributes to a class? 
__init__ is a constructor (runs automatically when an object is first created)
class Car:
    def __init__(self, brand, model)
        self.brand = brand
        self.model = model 

self refers to the object that is created.

What are methods?
Methods are functions inside a class 

Example:
class Employee:
    def __init__(self, name, gender, job_title, salary):
        self.name = name
        self.gender = gender
        self.job_title = job_title
        self.salary = salary

    def give_raise(self, raise_percentage)
        self.salary += self.salary * raise_percentage
    
How to use this class in a program?
emp1 = Employee("Alice", "F", "Programmer", 10000)
emp1.give_raise(10)
print(emp1.salary)
